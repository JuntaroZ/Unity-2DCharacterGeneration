# 最優先の蹴り脚指定：ユーザーの赤枠画像
- 脚の識別用参照画像：`C:\Users\junme\AppData\Local\Temp\codex-clipboard-f5058264-2669-44e8-ad04-9d75c217dd0b.png`。生成前にこの画像を実際に開き、赤枠で囲まれた脚を確認する。参照画像が見つからない場合は、推測せず不足を知らせる。
- ユーザーが赤枠で指定した脚が今回の「右脚」であり、必ずこの脚でミドルキックをする。赤枠は、基本姿勢の画面左下へ伸びている太もも・膝・すね・靴を囲んでいる。太ももに黒いベルトがない脚である。
- 赤枠の外にある画面右側の脚（黒い太ももベルト付き）が「左脚」であり、こちらを接地した軸足として残す。
- 動作の出発点を固定する：基本姿勢の赤枠内の右靴を地面から離し、その靴につながる右すね・右膝・右太ももを持ち上げ、右股関節から動かして画面右方向へ蹴り出す。赤枠外の左靴は接地を保つ。

- 右脚を前へ振り出す際は骨盤も自然に回す。上半身・骨盤を固定したまま反対側の脚を伸ばす形にしない。カメラは固定し、必要な身体の回旋で右脚の蹴りを表現する。
- ポケット、ショートパンツの裾、黒いベルトを反対側へ付け替えて、蹴り脚を正しく見せかけることは禁止する。衣装の目印だけでなく、胴体から骨盤、左右の股関節、脚への接続で判定する。
- この会話で先に生成した2枚のキック画像は、ユーザーが脚の逆転を指摘した不採用例である。正しいポーズの参照として流用しない。

# キャラ動作説明

- 「画面右側／画面左側」は基本ポーズで脚を識別するための位置であり、動作中に脚が交差しても左右の脚を入れ替えない

- 蹴り足が右に伸びた分、横幅の画像サイズは拡張してよいので、基本ポーズの体格を必ず維持

# 左右の脚を取り違えないための動作・構造指定
- 左右はキャラクター本人の解剖学的な左右で固定する。完成画像の画面上の位置から左右を付け直さない。
- 基本姿勢の画面左側にある、ベルトのない右脚を「右股関節 → 右太もも → 右膝 → 右足首 → 右靴」の一続きとして追跡し、この脚を持ち上げて蹴る。
- 基本姿勢の画面右側にある、黒い太ももベルト付きの左脚を「左股関節 → 左太もも → 左膝 → 左足首 → 左靴」の一続きとして追跡し、この脚を軸足として残す。
- 添付の実演写真は動作の参考とする。写真の人物の衣装・体型・撮影角度・背景・文字は取り入れず、キャラクターとカメラは既存の参照画像を維持する。
- 実演写真のように、左の軸足で身体を支え、体幹の軸を保ちながら骨盤を回して右脚を相手の胴の高さへ蹴り込む。蹴りのための自然な体幹の傾きは許容するが、上半身だけを大きく倒して脚を横へ突き出すポーズにしない。
- 左足は接地を維持し、必要に応じて足裏の前部を中心に自然にピボットする。右の股関節・膝・足先を連動させたミドルの回し蹴りとし、左脚を上げたポーズや別のサイドキックに置き換えない。
- 腰の回転に伴う骨盤、ショートパンツの左右の裾、太ももの付け根、膝の向き、脚の前後の重なりを整合させる。脚が交差しても股関節との接続を入れ替えない。
- 黒いベルトは補助的な目印であり、左右判定の唯一の根拠にしない。「左脚で蹴っている絵からベルトだけを接地脚へ移す」修正は禁止する。骨盤から靴までの接続で右脚の蹴りだと確認できること。

# 配置基準：体幹を中央に置き、左軸足の接地点を固定する
- 出力画像の高さは `right_middle_kick_end.png` と同じ1650pxに固定する。横幅は1800pxに限定せず、全身が収まる共通幅 `W` まで拡張してよい。
- `frame_01.png`～`frame_09.png` は、同じ幅 `W`、同じ高さ1650px、同じカメラ位置、同じ基本スケールに統一する。
- 「体の中心」は、髪、帯、両腕、両脚、蹴り足を除いた、胸郭、腹部、腰、骨盤からなる体幹部分の水平中心とする。全フレームで体幹中心を最終キャンバスの `X = W / 2` に合わせ、許容誤差は2px以内とする。
- 黒い太ももベルト付きの左脚を軸足とし、`frame_01.png` の左靴底の接地点を全フレーム共通の固定アンカー `(X_anchor, Y_ground)` とする。
- 左靴底の固定アンカーは、接地している靴底の中央点とする。`frame_02.png`、`frame_03.png`、`frame_04.png` ではこの点を `frame_01.png` と同じキャンバス絶対座標に固定し、X方向・Y方向とも許容誤差は2px以内とする。
- `frame_02.png`～`frame_04.png` で左軸足を画面左へスライドさせない。左股関節、左膝、左足首、左靴を連続した一本の支持脚として追跡し、接地点を基準に身体を支える。
- 蹴りに伴う左足の回転は、固定アンカーを中心とする足裏前部のピボットだけを許可する。靴全体の横移動、接地点の変更、踏み替え、滑りは禁止する。
- 体幹を中央へ合わせるために、フレームごとにキャラクター全体を左右へ平行移動したり、異なる量の左透明余白を追加したりしてはいけない。これが左軸足スライドの原因になるため禁止する。
- 体幹中央と左足アンカーの両方を満たすよう、左足を固定したまま、骨盤の回旋、右股関節の動き、自然な体幹の傾きでポーズを構成する。蹴り足の長さに合わせてキャラクター全体を左へ移動させない。
- 共通幅 `W` と共通の左右透明余白は生成前に一度だけ決め、全9フレームで同じ値を使用する。フレーム別のキャンバスオフセットは禁止する。
- 頭頂、髪、手、指、帯、蹴り足、軸足、両方の靴を完全に収め、左右に透明余白を残す。キャラクターをフレームごとに拡大、縮小、変形しない。
- 垂直方向のカメラ位置も固定する。地面相当位置 `Y_ground`、左足の接地Y座標、出力高さ1650pxを全フレームで維持する。
- 生成後は全9フレームへ共通の水平中心線 `X = W / 2`、左足アンカーの垂直線 `X = X_anchor`、地面線 `Y = Y_ground` を重ねて比較する。
- 特に `frame_01.png`→`frame_02.png`→`frame_03.png`→`frame_04.png` について、左靴底中央の座標差が各軸2px以内で、体幹中心も中央線から2px以内であることを数値確認する。超過した場合は不合格とし、左足アンカーを動かさずポーズを修正して出力し直す。

# 画像生成の出力方法
- 最初に赤枠の参照画像と照合する。赤枠内にあった右脚が蹴り脚で、赤枠外にあった左脚が接地脚であることを、骨盤から靴まで追跡して確認する。判断が曖昧な場合は合格にしない。
- 完成形では、黒い太ももベルトがある左脚が地面に接地したまま、ベルトのない右脚が画面右方向へ蹴り出されていることを確認する
- 完成形をfighting_base.pngと見比べ、基本姿勢で画面左側にあった右脚が右股関節から連続して蹴り脚につながり、画面右側にあった左脚が左股関節から接地した軸足につながることを確認する。ベルトの位置だけで合格としない。
- 完成形をfighting_base.pngと見比べ、左脚の黒い太ももベルトが右脚に移っていないことを確認する
- 蹴り足と軸足が逆、または黒い太ももベルトが蹴り足の右脚に付いている場合は、その画像を採用せず完成形を作り直す
- 完成形の右脚・左脚、キャラクターデザイン、向き、全身表示を確認するまで、出だし・戻りのフレームやZIPは生成しない
