# 下段ガードモーション（low_guard.md）

## 目的と参照
- 中段ガードの middle_guard.md を参考に、下段ガードの全4フレームを作成するための仕様。
- このファイルは Character/karen/anim/ に配置して使用する想定。配置先の AGENTS.md、../../common.md、../character.md を参照する。
- ../image.png をデザイン参照、../fighting_base.png を姿勢・向き・カメラ・身体スケール・体型の基準とする。
- 左右はキャラクター本人の左右。右脚を支持脚とし、左脚を「九の字」に曲げて少し浮かせる。
- 両腕は基本ポーズから変更しない。足を後ろへ下げてつま先を接地する動作は加えない。

## 出力と共通キャンバス
- frame_01.png～frame_04.png の全4枚、背景透過の RGBA PNG。
- 全枚を共通の W×1650 px とする。幅 W は660 px以上とし、必要な余白を全枚共通で追加する。横伸ばしや、収めるための縮小は禁止。
- 左余白 L、右余白 R を共通とし、W=660+L+R。元画像の座標 (x,y) は (x+L,y) に対応する。01は基本画像を原寸で配置し、描き直さない。
- 右足固定後、全4枚の胸郭中央・骨盤中央の左右移動範囲の中点がキャンバス中央付近になるよう、共通余白と全枚同じ水平移動量を決める。各フレームを個別に中央へ寄せ直さない。
- 縦方向は基本画像の接地線を維持する。髪・拳・膝・靴を含む全身を収める。
- 背景・床・影・文字・敵・エフェクトを追加しない。

## 優先順位と許容差
1. 同じ顔・髪・衣装・配色・向き・体型と自然な関節を維持する。
2. 両腕の基本の構え、右足の接地位置、全枚の身体スケールを維持する。
3. 左脚だけを九の字に軽く曲げ、左足を少し浮かせ、基本姿勢へ連続して戻す。
- 線・陰影・靴紐などの細かな生成差は許容する。別人化、細身化・脚長化、目立つ足滑り、逆関節・貫通・余分な手足は修正する。

## 右足の接地固定
- 01の右靴の靴底中央を接地アンカーとする。縦位置は基本画像のおよそ y=1598 px、横位置は元の右靴の座標に L を加えた位置を基準に、実画像で確認する。
- 02～04も同じアンカーを維持する。最終1650 px高で上下左右各3 px以内のずれを目標とし、通常再生で滑り・浮きが目立たないことを確認する。測定できない場合は未確認と記録する。
- 右靴の向き・傾き・大きさを維持する。身体スケールを合わせた後、全身の平行移動によるアンカー補正を許容する。
- 靴の局所編集や輪郭に沿った合成を行う場合は、足首との自然な接続を維持し、継ぎ目や二重輪郭を残さない。

## 体型・スケールの維持
- image.png と fighting_base.png を基準に、頭の大きさ、肩幅、胸郭・腰の幅、胴体の長さ、腕・脚の太さと長さを01と同倍率で比較する。
- 足を上げたことによる姿勢の変化と、身体自体の大きさの変化を区別する。頭頂と靴底を揃えるために全身を縮小しない。
- 解像度が異なる場合は、頭部と胴体など複数の目印で倍率を決め、縦横比を保って全体をリサイズする。部位だけの伸縮は禁止。
- 同条件で計測できる目印は01から概ね5%以内を目安とする。遮蔽や遠近で比較できない部位を数値合格にしない。
- 筋肉・胸・腰の強調や衣装変更を加えない。

## 完成姿勢
- 右足で安定して支え、必要な分だけ骨盤と上体を右足側へ自然に寄せる。体幹は基本姿勢に近く保ち、強い前傾・横倒し・反り腰や深いしゃがみ込みは加えない。
- 右膝は自然に緩め、伸ばし切りを強制しない。
- 左脚は膝を軽く曲げ、腿から膝、折り返す下腿にかけて「九の字」を思わせる自然な輪郭にする。文字の形を無理に再現せず、膝・足首の関節が自然に見えることを優先する。
- 左足は地面から少し離す程度。左膝を腹部まで高く上げず、踵を臀部まで強く引き付けない。左足は左膝より下に保つ。
- 左脚を大きく前へ突き出したり後ろへ引いたりせず、蹴り・膝蹴りにしない。左足の踵・つま先とも接地させない。
- 両腕は基本ポーズの肩・肘・手首の関節角度、拳の向き、上体に対する相対位置を維持する。腕を下げる、拳を上向きに変える、肘を膝へ寄せる動作は加えない。
- 重心移動に伴い両腕が上体と一緒に移動することは許容する。独立した腕の上げ下げは行わない。
- 視線は基本と同じ相手方向。顔を伏せたりカメラ目線にしたりしない。

## フレーム別の動作
| フレーム | 姿勢 |
|---|---|
| 01 | 原寸の基本画像を共通キャンバスへ配置したファイティング姿勢。右足の接地アンカーを決める。 |
| 02 | 右足へ自然に重心を移す。左膝を軽く曲げ、左足をわずかに浮かせる。左脚の曲がりと足の高さは01と03の中間程度。両腕は基本の構えを維持する。 |
| 03 | 左脚を九の字に軽く曲げ、左足を少し浮かせた完成姿勢。右足で安定して支える。両腕は基本の構えを維持し、左膝を高く引き上げない。 |
| 04 | 03から01へ戻る中間姿勢。左脚の曲がりと浮きをおよそ半分戻す。左足はまだ浮いており、04→01で基本の位置へ着地する。両腕は基本の構えを維持する。03の保持や01の複製にはしない。 |

## 作成・修正の手順
1. 03を先に作り、01と比較して左脚の小さな浮き、両腕の維持、顔・体型・右足の接地を確認する。
2. 03を動作参照として02・04を個別に作る。03の細かな生成差を他フレーム作成の停止理由にせず、全4枚の連続性を確認して修正する。
3. 編集は左脚と必要最小限の骨盤・支持脚を中心に行う。両腕や顔・衣装を無用に描き直さない。半透明合成や画像平均で中間姿勢を作らない。
4. 大きな再生成・修正は各フレーム原則2回までを目安とし、その後は最良候補に必要な仕上げを行う。回数制限を重大な不自然さの合格理由にしない。
5. 右足固定後に共通余白・身体中心・スケール・透過・足首の接続を仕上げる。
6. 未達が残る場合は「確認用・要修正」と明示し、具体的な箇所を記録する。参照不足やツール失敗で4枚を用意できない場合は不足内容を記録する。

## 検証と納品
- 通常再生は01→02→03→04→01。保持時は03を保持してから04→01で解除する。
- 4枚・共通寸法・RGBA PNG・透過・連番・全身表示を確認する。アルファチャンネルとグレー背景上で透過を確認する。
- 同倍率の全身比較、両腕・脚の拡大比較、右靴の重ね合わせ、ループプレビューを作る。
- 両腕が基本の構えを保っていること、左脚の九の字が自然で浮きが小さいこと、左足が接地していないこと、右足が滑らないこと、解除時に自然に着地することを確認する。
- 身体の中央配置、体型・スケール、顔の連続性、合成境界も確認する。
- 数値確認・目視確認・未確認を区別し、項目ごとに合格・許容差あり・要修正を記録する。
- W、L・R、右足アンカー座標とずれ、身体中心、スケール比較、残る制約を検証結果に記載する。
- frame_01.png～frame_04.png と、verification フォルダーの比較画像・ループプレビュー・検証結果をZIPにまとめる。
- クレジット消費量を取得できない場合は、その旨を記録する。
